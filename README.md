## Automated Deployment (Windows)

1. Download [`install_ritmada_core.bat`](./install_ritmada_core.bat) and [`ritmada_core_bundle.zip`](./ritmada_core_bundle.zip) into the same folder.
2. Run `install_ritmada_core.bat`.

The script will automatically:
- Resolve the target Antigravity path (`%USERPROFILE%\.gemini`).
- Generate a timestamped backup of your existing `.gemini` directory.
- Cleanly purge outdated configs, rules, and domains.
- Extract and verify the entire Ritmada Core v2.5 bundle.
